## Overview

TCPASF Advanced Security Tool is a comprehensive suite of utilities designed for network analysis, security testing, and system administration. This tool combines multiple functionalities in one powerful package with an intuitive console interface.

## Features

### IP Tools
- IP Lookup - Get detailed information about any IP address
- Port Scanner - Scan for open ports on target systems
- Domain Checker - Verify domain information and status
- Pinger - Test connectivity to hosts
- Nmap Integration - Advanced network scanning capabilities

### FiveM Tools
- CFX to IP Converter - Convert CFX addresses to IP addresses
- IP to JSON - Extract server information from FiveM servers
- Server Information - Get detailed server stats and player information

### Discord Tools
- Token Checker - Verify Discord token validity
- Webhook Spammer - Test webhook security
- Discord Server Nuker - Server administration and testing tools
- Discord Account Nuker - Account management utilities

### Additional Features
- User-friendly console interface with ASCII art
- Color-coded output for better readability
- Secure login system with admin privileges
- System information display

1. Clone the repository
2. Install required dependencies
3. Run `main.py` to start the application

```bash

```
